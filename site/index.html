Your agent can ask where you are. Only when it asks.

Whereabot lets Claude, ChatGPT or any MCP client ask your phone for its location, with your consent. Nothing is stored.

Add to your agent View on GitHub

How it works

  1. 1

    Install the app

    On your phone. See Install on your device.

  2. 2

    Sign in on your phone

    Open the app and sign in with Google. Keep it open while your agent asks.

  3. 3

    Add the relay

    Add the relay URL to your agent. See Add to your agent.

  4. 4

    Ask

    Your agent calls get_phone_location. You approve on your phone, and it sends its GPS fix back.

Your agentRelayYour phone reads GPS

The answer returns the same way. Until push notifications ship, keep the app open to answer.

What you can ask

  • "Find a kosher restaurant open near me now."
  • "How long until I get home?"
  • "Which station am I closest to?"

Get started

You need both: your agent asks, your phone answers.

Add to your agent

Relay URL

https://relay.whereabot.io/mcp

Claude Code

claude mcp add --transport http whereabot https://relay.whereabot.io/mcp

Then run /mcp and sign in.

Claude.ai and Claude Desktop
Settings → Connectors → Add custom connector. Paste the relay URL, then sign in.
Other MCP clients
Add the relay URL as a streamable HTTP server. The client opens the sign-in page.

You sign in in the browser (OAuth). No API keys. Use the same Google account as on your phone. More in the docs.

Privacy

Asked, not watched
Your phone reads its location only when your agent asks.
Nothing stored
The relay keeps no location history. A fix lives in memory for one request.
Revocable access
Each agent signs in separately. Remove its access any time by signing out of it or revoking it.
