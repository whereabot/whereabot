Your agent can ask where you are. Only when it asks.

Whereabot lets Claude, ChatGPT or any MCP client ask your phone for its location, with your consent. Nothing is stored.

Add to your agent View on GitHub

How it works

  1. 1

    Add the relay URL

    Add the relay URL to your MCP client. See Add to your agent.

  2. 2

    Sign in once

    Your client opens a browser. Sign in with Google and approve the request. No token to copy.

  3. 3

    Ask

    Your agent calls get_phone_location. Your phone reads its GPS fix now and sends it back.

Your agent Relay Your phone reads GPS

The answer returns the same way. For now, the app must be open to answer.

What you can ask

  • "Find a kosher restaurant open near me now."
  • "How long until I get home?"
  • "Which station am I closest to?"

Add to your agent

Run this in Claude Code. Your client opens a browser and asks you to sign in once.

Other MCP clients: add https://whereabouts-relay-prod-yz6gmxu7na-ew.a.run.app/mcp as an HTTP server. Sign in when asked.

Privacy

Asked, not watched
Your phone reads its location only when your agent asks.
Nothing stored
The relay keeps no location history. A fix lives in memory for one request.
Revocable access
Each agent signs in separately. Remove its access any time by signing out of it or revoking it.
Open source
MIT licensed. Read the relay and app code yourself.
