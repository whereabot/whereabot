Your agent can ask where you are. Only when it asks.

Whereabouts lets your AI agent ask your phone where you are, with your consent. Nothing is stored.

Get started Add to your agent

How it works

  1. Create an agent key

    Sign in with Google in the phone app. Create a key that starts with wb_. The app shows it once.

  2. Connect your agent

    Add the relay as an MCP server with one command. See Add to your agent.

  3. Ask

    Your agent calls get_phone_location. Your phone reads its GPS fix now and sends it back.

Your agent Relay Your phone reads GPS

The answer returns the same way. For now, the app must be open to answer.

What you can ask

  • "Find a kosher restaurant open near me now."
  • "How long until I get home?"
  • "Which station am I closest to?"

Add to your agent

Create a key in the app first. Then run this, replacing <relay-url> and wb_....

claude mcp add --transport http whereabouts <relay-url>/mcp --header "Authorization: Bearer wb_..."

Other MCP clients: point them at <relay-url>/mcp with the same bearer header.

Privacy

Asked, not watched
Your phone reads its location only when your agent asks.
Nothing stored
The relay keeps no location history. A fix lives in memory for one request.
Revocable keys
Each agent has its own key. Revoke it in the app at any time.
