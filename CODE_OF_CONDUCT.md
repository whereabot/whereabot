# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions and any other project space.

## Report a problem

Report unacceptable behavior privately to the maintainers. Use [private vulnerability reporting](SECURITY.md#report-a-vulnerability) and start the title with "Conduct". The maintainers keep the reporter's identity private and follow the Covenant's enforcement guidelines.
