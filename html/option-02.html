How to install from the browser

Install from the browser: steps and limits.

Add to your agent

Relay URL

https://relay.whereabot.io/mcp

Claude Code

claude mcp add --transport http whereabot https://relay.whereabot.io/mcp

Claude.ai and Claude Desktop: Settings → Connectors → Add custom connector. Paste the relay URL, then sign in.

Other MCP clients: Add the relay URL as a streamable HTTP server. The client opens the sign-in page.

Sign in and ask

Claude Code: Then run /mcp and sign in.

Claude.ai, Desktop and other clients open the sign-in page for you.

You sign in in the browser (OAuth). No API keys. Use the same Google account as on your phone. More in the docs.
